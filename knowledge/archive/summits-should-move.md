## A dead belief that stayed reachable for weeks

`jobs/wang-meng/STATE.md` carried, as an open defect:

> MIST (class `drift`) is unbuilt, so the summits above the compound hold
> perfectly still -- and those are exactly what the highest stations frame.

An earlier session wrote that. It was never measured, never agreed, and it was
wrong: distant peaks are *supposed* to hold still. But it sat in a file loaded
automatically at the start of every session, in the same voice and format as
measured verdicts, and it was read as live work for weeks. It caused 13 summit
gust regions to be authored and built before Ryan looked at the result.

This is the exact case for revocation over append-only storage. Under a
reversal, append-only memory measures 0.210 and NO MEMORY AT ALL measures 0.309
-- append-only is *worse than amnesia*, because amnesia fails honestly and a
stale note fails persuasively. Revocation measures 0.950
(TEPA, arXiv:2608.07429).
